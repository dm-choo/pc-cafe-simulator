# G002 — 첫 손님과 첫 매출

이슈 #2, 선행 G001 PR #11(main 통합). 상태: 구현 후 검증 중.

## 플레이어 흐름

카운터에서 영업 시작 → 손님이 입장해 빈자리를 예약 → 가구를 피해 좌석으로 이동 → 이용 → 한 번만 결제 → 퇴장. 현장에서는 사람이 움직이고 카운터와 HUD에서는 점유·현금·최근 결제를 확인합니다. 신규 입장 중지는 이용 중인 손님의 세션을 취소하지 않습니다.

## 구현 계약

- 50ms 고정 스텝. 1/4배속은 같은 tick에서 동일한 사업 결과를 만들며, 사장 이동은 별도 1배속 clock입니다.
- 가격 1,500원·40 sim초 = 사업상 1시간은 시험 밸런스 값입니다. 실존 제품·기준일 시장 가격을 구현했다고 보고하지 않습니다.
- 좌석 예약은 입장 명령에서 원자적으로 적용하고, 사용 완료 및 경로 실패 시 반환합니다. 종료 이전 결제와 종료 재입력은 무시합니다.
- 0.25m 정적 격자 경로, 가구에서 0.18m 여유. 의자 접근점은 옆으로 0.72m 확보합니다. 앉기/일어서기 구간은 임시 표현이며 G003에서 자세를 정리합니다.
- 현재 레이아웃은 고정입니다. 배치 확정은 없으며 NPC 서로 간·사장과의 물리 충돌은 없습니다.
- 고객은 퇴장 시 활성 목록에서 제거, 최근 결제는 30건 보관, 누적 매출/인원과 ID는 유지합니다. 저장은 G005 범위입니다.

## 검증

기존 BASIC-12 외 FIRST-SALE을 실제 카운터 조작으로 실행합니다. 규칙 검사는 전 좌석 경로, 만석·예약 중복, 조기/중복 결제, 경로 실패 반환, 마감 후 정산, 1/4배속 결과 일치를 확인합니다. 성공 명령·커밋·실제 화면은 [현재 상태](../production/status.md)에 기록합니다.
