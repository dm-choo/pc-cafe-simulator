제품 계획 v0.3은 이 대화에서 작성한 계획을 가져온 뒤, 최신 사용자 요청인 **0석 창업**을 반영했습니다. 이번 조사로 그 계획을 폐기하거나 세부 현실 복제로 되돌리지 않습니다. 과거 v0.1/v0.2의 파일은 현재 작업 공간에 없어 복원본을 만들어 넣지 않았습니다. 이번 구현 계약은 [0석 창업](tasks/004-zero-seat-opening.md)입니다.

제품의 첫 완성판 `v0.1`과 문서 개정판 `v0.3`은 서로 다른 버전입니다. 제품 목표와 구현 제안이 충돌하면 사용자 합의와 제품 계획을 먼저 확인합니다. 근거가 부족한 수치는 **설계 가정**, 실제 확인한 결과는 **검증 결과**로 표시합니다.

## 읽는 순서

- 개발 시작: 루트 AGENTS → 현재 상태 → 작업서 → 관련 아키텍처/검증 부분.
- 기획 확인: 게임 계획 → 백로그 → 가격·콘텐츠 정책.
- 협업 방식을 바꾸기: 연구 보고서 → 워크플로 → 결정 기록.
- 아트 작업: 게임 계획 6장 → 에셋 제작 → 검증 장면.

모든 에이전트에게 모든 문서를 매번 읽히지 않습니다. 작업 번호와 관련 파일을 링크하고, 완료 증거는 PR에, 다음 작업은 현재 상태에 남깁니다. 채팅 기록만으로 프로젝트를 이어가게 만들지 않습니다.
