# 결정 기록

2026-09-07. 사용자 합의는 [게임 계획 v0.3](../product/plan.md)이 기준입니다. 아래는 해당 방향을 구현하기 위한 현재의 시작 결정입니다. 새 결정이 이전 것을 대체하면 이유와 관련 PR을 여기에 남깁니다.

| ID | 결정 | 이유·효과 | 다시 검토할 조건 |
| --- | --- | --- | --- |
| D001 | 사장다운 판단·재미·현실풍 성능을 우선 | 정밀 하드웨어 복제가 영업과 선택을 지연하지 않음 | 사람 테스트에서 특정 현실 요소의 부재가 판단을 훼손 |
| D002 | TypeScript/Vite/Three WebGL2, DOM 경영 UI | 정적 웹 배포와 장면 제어에 맞는 작은 구조 | 필요한 효과·병목이 다른 선택의 비용을 정당화 |
| D003 | sim이 직렬화 가능한 사업 상태를 소유 | 배속·저장·테스트·화면 독립성 | 실제 구현에서 구체적 경계 문제가 생김 |
| D004 | 한 통합 책임자, 제한된 별도 역할 | 작은 팀의 공유 설계·충돌 비용을 줄임 | 안정된 계약과 실제 병렬화 이익이 확인되고 위임 승인 |
| D005 | 같은 게임의 작은 영업부터 누적 | 재미·아트 제작·웹 성능을 일찍 함께 확인 | 제품 방향 자체가 사용자에 의해 변경 |
| D006 | 2026-01-01 가격 근거와 밸런스 값 분리 | 현실감 유지와 초기 진행 속도 조정 가능 | 시나리오의 시대·시장 기준 변경 |
| D007 | 버전 저장·정상 백업·JSON 내보내기 | 서버 없는 게임의 이어하기와 복구 | 로그인·클라우드 저장이 명시적으로 필요해짐 |

D001·D005·D006은 사용자 수정 의도를 유지하는 결정입니다. 다른 결정과 세부 수치는 검증할 구현안입니다. 별도의 승인 회의나 과도한 ADR 파일을 만들기보다 실제 변화의 이유를 남기는 데 사용합니다.
