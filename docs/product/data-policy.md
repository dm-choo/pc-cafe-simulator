# 실제 제품·가격·게임 데이터 정책

목표는 실제 PC방 사장의 구매 감각을 설득하는 것입니다. **가격 참고일은 2026-01-01, 대한민국, KRW**입니다. 아직 해당 날짜의 제품 가격표를 완성하지 않았습니다. 아래는 데이터 수집·사용 방식이며 실제 가격 데이터가 아닙니다.

## 1. 카탈로그 최소 단위

처음에는 현실의 3개 내외 추천 PC 구성과 소수의 GPU·RAM·모니터·마우스·키보드·의자 대안을 제공합니다. 장비 수를 늘리기 전에 가격·고객층·효과를 읽고 선택할 수 있어야 합니다. 설치된 원작 게임은 카탈로그·수요·성능 요구의 형태로 표현합니다. 브라우저 안에서 원작 클라이언트를 실제 실행하거나 유료 게임 파일을 배포하지 않습니다.

| 데이터 | 보관할 항목 | 표시 원칙 |
| --- | --- | --- |
| 제품 | ID, 실존 이름, 분류, 주요 사양, 중요 호환성, 외형 연결 ID | GPU 등급 하나만으로 주변기기 품질을 대체하지 않음 |
| 가격 관찰 | 출처 URL, 관찰 가격, 해당 날짜, 조회 날짜, 신품/중고, VAT·배송 등 확인 범위 | 정확한 당일·근접 시점·임시 가정을 구분 |
| 게임 내 적용값 | 적용 가격, 근거 관찰 ID, 기준일, 조정 이유 | 근거 없는 정밀성을 표시하지 않음 |
| 게임 | 이름, 제공 여부, 요구 성능 범주, 고객 선호, 화면 자산 ID | 실제 벤치마크와 게임 내 추정 구별 |
| 밸런스 | 시작 현금, 유입, 선호 분포, 시간 압축, 목표 | 현실 관찰값과 별도 버전 |

가격의 근거 상태는 `verified-date`, `near-date`, `assumption`으로 구분합니다. `verified-date`는 출처에서 당일 조건을 확인한 경우만 사용합니다. 현재 판매가를 2026-01-01 가격으로 대입하지 않습니다. 정확한 당일 자료가 없으면 필수 개발을 멈추지 않고 임시값을 표시합니다.

## 2. 현실과 재미를 조정하는 순서

1. 구매 이유가 보이는지 확인합니다. 고객의 요구·현재 불만·대기열이 단서가 되어야 합니다.
2. 시작 매장 상태, 현금, 유입·지급 리듬과 시간 압축으로 첫 투자가 지나치게 늦지 않게 조정합니다.
3. 충분한 성능 이후에는 의자·모니터·서비스가 더 중요한 고객도 둡니다.
4. 장비 가격을 바꿔야 하면 근거 가격과 게임 적용값을 분리하고 변경 이유를 기록합니다.

투자 수익률을 언제나 정확히 알려주는 최적해 계산기를 기본 UI로 만들지 않습니다. 대신 현재 병목, 예상되는 고객층, 비용 부담을 보여주고 플레이어가 결과로 배웁니다. 단순한 첫 선택은 회복하기 쉬운 비용으로 제공합니다.

## 3. 자료와 에셋

제품 정보의 사실 조사와 제조사 사진·로고·게임 영상의 재배포 가능 여부는 별개입니다. 원문 링크는 출처로 기록하고, 배포 화면 자산은 직접 제작하거나 적절한 사용 조건이 확인된 자료를 사용합니다. 조건 미확인 이미지를 공개 빌드에 넣어야만 실존 타이틀을 표현할 수 있는 것은 아닙니다.

첫 구현은 자체 제작한 모니터 화면과 텍스트 카탈로그로 진행할 수 있습니다. 실물 사진은 비율·재질의 참고이며 곧바로 배포용 텍스처로 간주하지 않습니다. 자산별 기록은 [아트 파이프라인](../art/pipeline.md)에 따릅니다.

## 4. 변경과 검증

제품 ID를 유지하고 데이터에 버전을 부여합니다. 호환성 오류는 규칙 검사, 밸런스 변경은 고정 seed의 서로 다른 고객층 시나리오에서 검토합니다. 프리미엄·가성비·음식 중심 전략 각각이 특정 조건에서 성립하는지 확인하되 모든 상황에서 동일한 수익이 나게 조정하지 않습니다.

첫 데이터 조사 작업은 G004에 필요한 장비부터 시작합니다. CPU·GPU 전체 시장 목록, BIOS, 모든 판매점의 일별 변동 추적은 첫 완성판의 선행 조건이 아닙니다.
